  1. Buka Google Drive → Baru → Google Spreadsheet kosong.
  2. Menu Ekstensi → Apps Script, lalu tempel isi file gas/Code.gs.
  3. Deploy → New deployment → tipe Web app → akses Anyone → salin URL /exec.

Kosongkan jika Script Property SYNC_TOKEN tidak dipakai.
